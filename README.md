# Daily Planner

A simple, responsive daily planner that runs in your browser. Add tasks, set
optional times, mark tasks complete, and move between dates. Your tasks are
stored locally in your browser and are not sent to a server.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are
required.

## Publish with GitHub Pages

The workflow in `.github/workflows/pages.yml` publishes the site when changes
are pushed to the `main` or `master` branch, or when manually started from the
Actions tab. In the repository settings, set **Pages → Build and deployment →
Source** to **GitHub Actions**. The workflow run will provide the public site
URL when deployment completes.
